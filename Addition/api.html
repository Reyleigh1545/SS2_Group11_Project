Overview

SkyCast combines real-time weather, environmental monitoring, geolocation, and visual media APIs to provide an immersive forecasting experience.

OpenWeather API

OpenWeather powers real-time weather conditions, forecast data, humidity, wind speed, and atmospheric metrics throughout the application.

Base Endpoint https://api.openweathermap.org/data/2.5/
  • Current weather data
  • Forecast predictions
  • Wind and humidity metrics
  • Temperature and condition icons

Open-Meteo API

Open-Meteo provides advanced meteorological forecasting and climate-related datasets for detailed environmental analysis.

Base Endpoint https://api.open-meteo.com/v1/
  • Hourly weather forecasts
  • Daily temperature trends
  • Climate modeling data
  • Forecast optimization support

AQICN API

The AQICN API powers global air quality monitoring, pollution maps, and AQI visualization across the interactive world map.

Base Endpoint https://aqicn.org/here/
  • Global AQI monitoring
  • Pollution heatmaps
  • Station-based air quality data
  • Environmental health indicators

API Security

API keys and sensitive credentials are protected through server-side configuration and environment variables whenever possible.

Usage & Limitations
